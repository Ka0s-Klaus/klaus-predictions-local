# Política de seguridad

## Versiones soportadas

El proyecto está en fase inicial. Hasta la primera release estable (`v1.0.0`) solo
se da soporte a la rama `main`.

| Versión | Soportada |
| ------- | --------- |
| `main`  | ✅        |

## Reportar una vulnerabilidad

**No abras un issue público para reportar un fallo de seguridad.**

Usa el canal privado de GitHub:

👉 [Reportar vulnerabilidad](https://github.com/Ka0s-Klaus/klaus-predictions-local/security/advisories/new)

Incluye en el reporte:

- Descripción del fallo y su impacto.
- Pasos de reproducción o prueba de concepto.
- Versión / commit afectado.
- Cualquier mitigación que conozcas.

## Qué esperar

| Fase                        | Plazo objetivo    |
| --------------------------- | ----------------- |
| Acuse de recibo             | 72 horas          |
| Evaluación inicial          | 7 días naturales  |
| Corrección o plan de acción | 30 días naturales |

Te mantendremos informado durante el proceso. Si el reporte se confirma,
publicaremos un advisory con crédito para quien lo descubrió, salvo que prefieras
permanecer anónimo.

## Divulgación responsable

Te pedimos que no divulgues públicamente el fallo hasta que exista una corrección
disponible o hayan pasado 90 días desde el reporte, lo que ocurra antes.

## Fuera de alcance

- Ataques de denegación de servicio por fuerza bruta.
- Vulnerabilidades en dependencias de terceros ya reportadas upstream (avísanos
  igualmente, pero repórtalas también en el proyecto de origen).
- Problemas que requieran acceso físico a la máquina del usuario.
- Resultados de escáneres automáticos sin prueba de explotabilidad.
